## Executive Summary
PT Industri Kereta Api (Persero) adalah BUMN yang bergerak di bidang manufaktur kereta api dan komponennya, dengan sekitar 4.000 karyawan. Perusahaan ini sedang melakukan transformasi digital dan memiliki program pengembangan SDM yang bertujuan meningkatkan kemampuan dan kompetensi karyawan. Fayolex harus prioritaskan ini sekarang karena PT Industri Kereta Api (Persero) memiliki potensi besar untuk mengadopsi LMS yang lebih efektif dan efisien, serta memiliki kebutuhan yang jelas untuk meningkatkan kemampuan dan kompetensi karyawan.
